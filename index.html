PocketBase 403 或欄位錯誤？檢查安全規則與資料欄位

在 PocketBase 為 transactions 與 budgets 建立以下欄位，名稱及大小寫須完全相同。金額設為 Number，其餘列出的欄位設為 Plain text；type 儲存 income 或 expense。不要另外建立 id 或 createdAt，PocketBase 會自行提供 id 和 created。

transactions

type: Text
amount: Number
category: Text
note: Text
allocationNote: Text（可選）
date: Text
month: Text
authorUserId: Text

budgets

month: Text
category: Text
amount: Number
authorUserId: Text

兩個集合的 List / View / Delete Rule：

@request.auth.id != "" && authorUserId = @request.auth.id

Create Rule：

@request.auth.id != "" && @request.body.authorUserId = @request.auth.id

若伺服器仍只回報「Something went wrong」，請查看 PocketBase 伺服器日誌以取得具體欄位錯誤。規則應限制本人資料存取；切勿啟用公開寫入或將管理員密碼放進網頁。
